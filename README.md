# scoop-bucket

Scoop manifests for my tools.

```powershell
scoop bucket add maclucky https://github.com/mac-lucky/scoop-bucket
scoop install maclucky/pushward
```

| Manifest | Source |
|---|---|
| `pushward` | [pushward-cli](https://github.com/mac-lucky/pushward-cli), the PushWard command-line client |

A release of the tool writes its manifest here, in `bucket/`. Don't edit it by hand.
